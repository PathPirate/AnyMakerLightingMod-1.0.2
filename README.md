# AnyMakerLightingMod-1.0.2

Adjust the Sun Light Strength, Ambient Light, Bloom, Freeze Time, remove weather

## Setup
1. Copy xinput9_1_0.dll next to game.exe in your AnyMaker installation folder.

## How To Use
1. Open the inventory to see the Lighting button. Top Left, click it to open/close the window.

## Note
If the button does not appear, check %LOCALAPPDATA%\AnyMakerLightingDll\lighting-diagnostic.log.
